# Golden test signals (pinned)
Generated by `python3 tools/gen_golden.py` (numpy, fixed PCG64 seeds), float32 WAV, 44.1/48/96 kHz.
`manifest.tsv` lists SHA-256 and expected values (ch0 RMS dBFS / peak / DC; delay and 2nd arrival in samples,
+ = mic later). Pair files are stereo: ch0 = reference, ch1 = mic. `golden_tests` (ctest prefix `golden:`)
verifies hashes and values via fohcore. Do not regenerate casually: a regenerated file must keep its hash.
